# 考研数学与408薄弱点遗忘追踪表 · v4 版本说明

> 更新日期：2026-11-21
> 对应文件：[408_v4.html](../408_v4.html)（单文件应用，数据文件 `shiyiyue_zhishidian.json`）

## 版本定位

以「遗忘次数」为核心驱动的考研薄弱点管理工具，配套每日待办，形成"记录 → 复习 → 追踪 → 掌握"的完整闭环。

---

## 核心特点

### 1. 双模块管理
- **考研数学**：高等数学 / 线性代数 / 概率论与数理统计
- **408**：数据结构 / 计组 / 操作系统 / 网络
- 两个 Tab 独立统计、独立筛选，互不干扰

### 2. 薄弱点记录（总结单元）
每条薄弱点包含完整上下文：

| 字段 | 说明 |
|---|---|
| 科目 / 知识点 | 定位薄弱点（如 "27\|李六\|物理应用"） |
| 错误类型 | 知识缺失 / 理解错误 等 |
| 来源 | 模拟题、模拟卷等 |
| 反思备注 | 记录为什么错、如何补救 |
| 状态 | 待解决 → 复习中 → 已掌握 |
| 遗忘次数 | 核心追踪指标 |
| 首次日期 / 最近日期 | 时间线追踪 |

### 3. 遗忘计数机制
- **"+1 遗忘"按钮**：复习时再次卡壳，一键计数 +1，并自动更新"最近遗忘日期"
- **防假掌握**：状态为"已掌握"的记录被点 +1 遗忘后，自动降级回"复习中"
- **高频预警**：
  - 遗忘 ≥ 3 次 → 红色卡片 + "🔥 高频易忘"标记
  - 2 次 → 黄色提示，1 次 → 蓝色

### 4. 统计面板
每个模块顶部四张统计卡：
- 📚 总记录数
- ⏳ 未掌握数（待解决 + 复习中）
- 🧠 累计遗忘次数
- 🔥 高频遗忘数（≥3 次）

### 5. 排序与筛选
- **排序**：默认按遗忘次数降序（忘得最多的排最前，优先复习）；支持最近日期、首次记录日期排序
- **筛选**：按科目、按状态
- **搜索**：关键词匹配知识点、来源、备注、科目

### 6. 双视图切换
- **大卡片视图**：磨砂玻璃质感、左侧状态色条、入场动画，适合沉浸式浏览
- **紧凑表格视图**：信息密度高，适合批量查看

### 7. 每日待办模块
- 按日期分组展示，含完成进度条
- 优先级（高/中/低）+ 分类标签
- 支持顺延到明天、快速添加、编辑、删除

### 8. 薄弱点 → 待办联动
- 任一薄弱点可一键"📅 加入待办"
- **优先级自动判定**：遗忘 ≥ 3 次自动设为"高"优先级
- 待办标题自动带上科目，备注自动携带反思内容和来源

### 9. 套卷记录模块（408 / 数学）
- 专记录**套卷**做题情况，仅支持 408 与数学两科
- 每张卷子记录：**小题分数 / 大题分数 / 总分（自动求和）/ 用时（分钟）/ 做题日期 / 系列分类（李六、张八、真题…）/ 总结反思**
- 卷子卡片下方列出**错误题**：题号 + 所属科目 + 错误点
- **错误题一键加入遗忘点**：点"＋ 遗忘点"即在对应科目薄弱点列表生成一条记录（自动带上卷名来源、题号备注、首次遗忘时间），加入后显示"✓ 已加入"，重复点击不会重复添加
- 顶部统计：总套卷数 / 数学套卷 / 408 套卷 / 错误题总数
- 支持按科目、系列筛选，按日期或总分排序，关键词搜索（含错误点）
- 删除套卷前自动留存历史快照；已加入遗忘点的记录不受删除影响

### 10. 分页与遗忘轨迹
- **分页渲染**：薄弱点卡片/表格视图均分页（每页 20/50/100 可选），记录增多时不再一次性铺满页面；筛选自动回到第 1 页
- **遗忘事件时间戳**：每次"+1 遗忘"自动记录精确时间，卡片显示紧凑"遗忘轨迹"（最近 5 次 + 间隔天数），编辑弹窗可查看完整历史；旧数据自动补种首/末两次已知日期（不伪造中间时间）

## 数据安全机制（三层存储 + 快照）

| 层级 | 机制 | 说明 |
|---|---|---|
| Tier 1 | IndexedDB 主存储 | 浏览器本地数据库 `KaoyanTrackerDB` |
| Tier 1.5 | localStorage 镜像 | 兜底备份，IndexedDB 不可用时自动降级 |
| Tier 2 | 本地 JSON 文件绑定 | 通过文件系统 API 直接读写 `shiyiyue_zhishidian.json`，可选"自动写盘"（每次修改即时写入硬盘） |
| Tier 3 | 历史快照 | 最多保留 **15 个滚动快照**，手动保存 / 删除记录前 / 绑定文件前自动备份，可随时恢复防误删 |

### 保存方式
- **自动写盘**：绑定本地 JSON 后可开启，每次修改即时同步硬盘
- **手动保存**：按钮或 `Ctrl+S` / `Cmd+S`
- **导入 / 导出 JSON**：完整数据可导出备份、迁移
- **脏状态提醒**：有未保存修改时显示"保存修改"提示，关闭页面前二次确认

### 兼容性
- 100% 兼容 v3 JSON 数据结构，首次打开自动迁移旧数据
- 支持记忆文件句柄：重新打开页面自动恢复与本地 JSON 的绑定
