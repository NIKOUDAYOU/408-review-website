# 408 总结网站 · 考研数学与 408 薄弱点遗忘追踪表 v4

以「遗忘次数」为核心驱动的考研薄弱点管理工具，单文件网页应用，配套每日待办与套卷记录，形成「记录 → 复习 → 追踪 → 掌握」的闭环。

## 功能概览

- 双模块：考研数学（高数 / 线代 / 概率论）、408（数据结构 / 计组 / 操作系统 / 网络），两个 Tab 独立统计与筛选
- 薄弱点记录：科目、知识点、错误类型、来源、反思备注、状态、遗忘次数、首次与最近遗忘日期
- 遗忘计数：一键「+1 遗忘」并更新最近遗忘日期；已掌握记录再次遗忘自动降级为「复习中」；≥ 3 次红卡 + 🔥 高频易忘预警
- 统计面板、排序 / 筛选 / 搜索、大卡片与紧凑表格双视图、分页渲染
- 每日待办：按日期分组、优先级、顺延到明天，薄弱点可一键“加入待办”
- 套卷记录：小题 / 大题 / 总分、用时、系列分类、错误题一键生成遗忘点
- 数据安全：IndexedDB 主存储 + localStorage 镜像 + 本地 JSON 文件绑定 + 最多 15 个滚动快照

## 使用方法

1. 用浏览器打开 `408_v4.html`（推荐 Chrome / Edge）
2. 首次使用点击“绑定本地 JSON”选择 `shiyiyue_zhishidian2.json`，可在“自动写盘”开启后即时保存
3. 数据同时写入浏览器 IndexedDB（库名 `KaoyanTrackerDB`），换机用“导出 / 导入 JSON”迁移
4. `Ctrl+S` 保存，`Esc` 关闭弹窗

页面需要联网加载 CDN 资源（Tailwind CSS、KaTeX 公式渲染、Inter 字体）；KaTeX 加载失败时降级为原始 TeX 文本。

## 兼容性

- 100% 兼容 v3 JSON 结构，首次打开自动迁移旧数据
- 支持记忆文件句柄：重新打开页面可恢复与本地 JSON 的绑定
