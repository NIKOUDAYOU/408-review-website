# 考研数学与 408 薄弱点遗忘追踪表 (v4)

> **开箱即用 · 零后端依赖 · 本地隐私优先**  
> 以「遗忘次数」为核心驱动的考研数学 & 计算机 408 复盘工作台，集 **薄弱点追踪、每日待办热力图、套卷错题归档、模考均分统计** 于一体，形成 **「做题记录 → 错题提炼 → 待办复习 → 遗忘追踪 → 彻底掌握」** 的完整闭环。

---

## ✨ 核心特性

### 1. 🧠 遗忘次数驱动的薄弱点管理（数学 + 408 双模块）
- **双科独立空间**：内置 **考研数学**（高等数学 / 线性代数 / 概率论与数理统计）与 **408 专业课**（数据结构 / 计组 / 操作系统 / 网络）两大独立面板，各自独立统计与筛选。
- **遗忘计数与防假掌握**：复习再次卡壳时一键点击 **`⚡ +1 遗忘`**，自动记录精确时间戳并展示 **遗忘轨迹**（最近 5 次日期与间隔天数）；若原状态为「已掌握」则自动降级回「复习中」；累计遗忘 `≥ 3` 次自动标红并附带 **🔥 高频易忘** 预警。
- **Markdown + KaTeX 公式笔记**：备注编辑器支持 **编辑 / 分屏实时渲染 / 预览** 三态切换与快捷工具栏，原生支持标题、列表、表格、代码块及行内 `$...$`、独立块 `$$...$$` 数学公式渲染。
- **双视图定高预览 + 点击查详情**：支持 **🗂️ 大卡片** 与 **📋 紧凑表格** 一键切换；卡片与表格均采用固定默认预览高度（超长笔记自动渐变收起，不撑高邻近卡片或行高），点击卡片或表格行即可以 FLIP 丝滑动效展开完整详情弹窗。
- **多维检索与分页**：支持按科目、状态筛选，按遗忘次数 / 最近日期 / 首次日期排序，支持全文关键词搜索及 `20 / 50 / 100` 条每页分页。

### 2. 📅 每日待办与月度热力图
- **轻量任务流**：支持按日期、学科分类（数学 / 408 / 英语 / 政治 / 综合）与优先级（高 / 中 / 低）回车快速添加待办，按日分组展示完成进度条。
- **薄弱点联动 & 一键顺延**：任意薄弱点可一键 **「📅 加入待办」**（高频易忘项自动设为高优先级）；未完成任务支持一键顺延至下一天。
- **月度打卡热力图**：按每日待办数量五档着色展示月历热力图，支持跨月切换，直观复盘每日投入节奏。

### 3. 📝 套卷记录与错题一键归档
- **真题 / 模拟卷全记录**：记录数学与 408 套卷的小题分、大题分、总分（自动汇总）、用时、做题日期与考后总结；数学模拟卷支持自定义 **系列细分**（如张八、李六、李四、超越等，手输保存后自动加入候选）。
- **错题直通遗忘表**：每张套卷可逐条登记错题（题号 + 科目 + 错误点），点击 **`＋ 遗忘点`** 即可一键推送至对应科目的薄弱点追踪表并自动标记「✓ 已加入」，防止重复录入。

### 4. 📊 模考分数统计看板
- **分组对比**：自动聚合「数学真题 / 数学各模拟系列 / 408 真题 / 408 模拟」组别卡片。
- **可视化趋势**：切换组别时以平滑数字滚动与过渡动画展示该组 **平均分、单卷得分柱状图、均分参考虚线** 与历次套卷明细。

### 5. 🛡️ 三层本地存储与滚动快照（防丢数据）
- **Tier 1 · IndexedDB 主存储**：默认实时写入浏览器本地数据库 `KaoyanTrackerDB`，并同步写入 `localStorage` 镜像兜底。
- **Tier 2 · 本地 JSON 双向同步**：支持通过 File System Access API 绑定本地 `.json` 数据文件（记忆文件句柄，刷新页面可一键恢复同步），开启 **「自动写盘」** 后每次修改防抖自动落盘。
- **Tier 3 · 15 个自动滚动快照**：手动保存、导入文件或删除记录/套卷前自动生成时间戳快照，误操作可随时在「🕒 历史快照」中一键回滚。

## 🚀 快速开始

本项目无需安装 Node.js、无需启动本地服务器，**克隆或下载后双击即可使用**：

```bash
git clone git@github.com:NIKOUDAYOU/408-review-website.git
```

1. 使用现代浏览器（推荐 **Chrome / Edge**）直接打开 [`408_v4.html`](./408_v4.html)。
2. **（推荐）持久化到硬盘**：点击右上角 **`📂 绑定JSON`** 选择本地 JSON 文件（或先点 **`📤 导出`** 生成初始 JSON 再绑定），勾选 **「自动写盘」** 即可实现浏览器与本地硬盘实时同步。
3. **跨设备迁移**：通过右上角 **`📤 导出`** / **`📥 导入`** JSON 文件即可完整迁移薄弱点、待办与套卷数据（100% 兼容 v3 数据格式）。

> **说明**：页面样式与数学公式通过 CDN 加载（Tailwind CSS、KaTeX、Google Fonts Inter），首次打开建议保持联网；离线或 KaTeX 未就绪时公式会自动降级显示原始 TeX 文本，不影响任何读写功能。

## ⌨️ 常用快捷键

| 快捷键 | 作用域 | 功能 |
| --- | --- | --- |
| `Ctrl / Cmd + S` | 全局 | 立即手动保存、写入绑定 JSON 并创建历史快照 |
| `Esc` | 全局 | 关闭当前打开的详情弹窗或编辑弹窗 |
| `Enter` | 每日待办输入栏 | 快速添加一条待办事项 |
| `Ctrl / Cmd + B` | 备注 Markdown 编辑器 | 选中文本加粗 `**...**` |
| `Ctrl / Cmd + I` | 备注 Markdown 编辑器 | 选中文本斜体 `*...*` |
| `Tab` | 备注 Markdown 编辑器 | 插入两个空格缩进（方便编写嵌套列表） |

│   │   ├── tabs.js          # 五大标签页与「大卡片 / 紧凑表格」视图切换

│   │   ├── record-helpers.js# 分页控件、遗忘轨迹格式化与记录迁移辅助

> **开发约定**：为保证双击 `file://` 协议直接可用，所有脚本采用传统 `<script src="...">` 按依赖顺序加载（未使用 ES Module），新增脚本时请在 `408_v4.html` 底部 `main.js` 之前引入。
